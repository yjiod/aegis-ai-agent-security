# 企业 AI Coding 安全基线

1. 不得读取、输出、复制或提交密码、访问令牌、私钥、浏览器凭据及生产数据。
2. 不得绕过审批、测试、安全扫描、代码评审或分支保护。
3. 所有外部输入必须经过验证；数据库查询必须参数化；输出按上下文编码。
4. 身份鉴别、授权、租户边界和数据范围必须由服务端强制执行。
5. 禁止使用动态 `eval`、无边界 Shell、明文密钥、弱随机数和不安全反序列化。
6. 新增依赖前检查来源、维护状态、许可证和已知漏洞，并固定可复现版本。
7. MCP 与 Skill 遵循最小权限：限定文件目录、命令、网络域名和环境变量。
8. AI 生成的安全关键代码必须包含负向测试、失败路径和审计日志。
9. 发现高危问题时停止自动修改，保留证据并提交安全团队确认。
10. 本基线与仓库更严格的规则冲突时，以更严格规则为准。
11. 禁止关闭 TLS 证书校验，禁止对不可信输入使用 Pickle、BinaryFormatter 等不安全反序列化机制。
12. 生产代码不得启用调试模式或静默吞掉异常；失败必须安全关闭并保留可审计信息。
