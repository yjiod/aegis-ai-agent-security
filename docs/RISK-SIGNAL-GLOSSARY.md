# 风险信号人话说明（Skill / MCP 扫描结果怎么看）

> 目标：让非安全背景的使用者看懂扫描结果里的 `exec=9`、`score=4`、`高危/中危/低危`、`加白/观察/拉黑` 到底是什么意思。
> 对应代码：`aegis_agent.py` 的 `skill_risk_score()`。

---

## 一、四个"风险信号"是什么（能力维度）

扫描器不看 Skill/MCP"坏不坏"，而是看它**拥有哪些能力**。有能力不等于恶意，但能力越大、一旦被利用危害越大。四个维度：

| 信号 | 人话含义 | 举例 |
|------|---------|------|
| **exec**（执行） | 它能**运行命令/代码**。比如调用 shell、跑脚本、起子进程。 | 一个 Skill 里写了"帮我执行 `npm install`"，就记 1 处 exec。 |
| **cred**（凭据） | 它会**读取或使用密钥/令牌/密码**。 | 读取环境变量里的 API Key、读 `~/.ssh`、读浏览器凭据。 |
| **network**（外联） | 它会**向外联网**（请求外部服务器）。 | 调用某个 https API、上传数据到第三方。 |
| **filewrite**（写文件） | 它会**写/改你电脑上的文件**。 | 生成配置文件、修改代码、写日志到磁盘。 |

---

## 二、`exec=9` 里的数字 = "发现几处"，不是"多危险"

- `exec=9` 意思是：扫描器在这个 Skill 里**找到了 9 处**会执行命令的地方。
- 它衡量的是**出现次数**，次数多≠一定更危险，只是"这个 Skill 到处都在跑命令"。
- 同理 `cred=2` = 2 处碰凭据，`network=3` = 3 处外联。

---

## 三、`score` = "能力有多全"，0~6 分

score 不看次数，只看**这四类能力各自"有没有"**，有就加分（每类只算一次）：

```
score = exec有? +2 : 0
      + cred有? +2 : 0
      + network有? +1 : 0
      + filewrite有? +1 : 0     （满分 6）
```

- 权重含义：**执行(2) 和 碰凭据(2) 最危险**，各占 2 分；外联(1)、写文件(1) 次之，各 1 分。
- 一个只会执行命令的 Skill：score = 2（中危）。
- 一个"能执行 + 能外联 + 能写文件"的 Skill：score = 2+1+1 = 4（高危）。
- 一个"能执行 + 能碰凭据"的 Skill：score = 2+2 = 4（高危）。

### 为什么会出现 `exec=9, score=4`？
- `9` 是 exec 的**出现次数**（9 处执行点）。
- `4` 是**能力组合分**：exec 只算一次(+2)，再加上它同时具备的外联(+1)、写文件(+1) = 4。
- 所以"次数多"和"分数高"是两回事：**次数描述"用了多少次"，score 描述"集齐了几种危险能力"**。score 到 4 就进高危档。

---

## 四、score → 严重度档位

| score | 档位 | 人话 |
|-------|------|------|
| ≥ 4 | 高危 | 集齐了"执行+凭据"或"执行+外联+写文件"等强组合，重点盯 |
| 2–3 | 中危 | 有单一较强能力（如只会执行、或只会碰凭据），需留意 |
| < 2 | 低危 | 能力很弱（如只读不写、不外联），基本放心 |

> 最终展示的严重度 = max(风险信号档位, 该类别预制规则档位)。即某些类别（如"开发辅助"vs"云服务调用"）有预设的最低关注级别，取两者更高者。

---

## 五、处置三态：加白 / 观察 / 拉黑

| 处置 | 人话 | 效果 |
|------|------|------|
| **加白（allow）** | "我信它，放行" | 加入允许名单，不再告警；但仍记录调用审计。 |
| **观察（monitor）** | "先放着，盯着它" | 不阻断，但持续上报它的行为，供你复查。 |
| **拉黑（deny）** | "不准用" | 加入阻断名单，终端拦截并告警。 |

打标 = 给 Skill/MCP 贴一个业务标签（如"研发工具""第三方 SaaS""内部脚本"），便于按类批量处置与统计；处置 = 上面三态之一。

---

## 六、给使用者的一句话速记

> **看 score 定危不危险（≥4 高危），看 exec/cred/network/filewrite 的数字知道它"会干什么、干了几次"，再用 加白/观察/拉黑 决定放不放行。**
