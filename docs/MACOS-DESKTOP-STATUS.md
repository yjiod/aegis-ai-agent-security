# Mac 统一客户端桌面状态契约

状态：开发候选。此增量替换旧 Swift 界面的独立扫描器、策略读取器、身份生成和上报配置。系统服务为唯一治理与上报引擎，Swift AppKit 界面展示其最近诊断结果。用户终端不依赖 Python 或开发工具；不修改受管安全基线。

## 公开最小状态

已安装的自包含系统 watch 父进程每 60 秒调用内嵌诊断，在固定系统应用目录原子发布 `desktop-status.json`。开发源码、一次扫描子进程及维护命令不启动发布器。线程退出最多等待 0.2 秒，诊断阻塞不能占用扫描看门狗的信号与超时处理。

`aegis.desktop-status/v1` 仅允许 schema、客户端版本、策略版本（不可确认时为 unknown）、检查时间、七个布尔值：安装、完整性、系统服务、上报配置、最近上报、报告有效性、扫描时效。所有字段由白名单重新构建。任何非布尔 true 均按未通过处理。不发布设备/用户身份、路径、原始报告、问题列表、片段、凭据或精确风险评分。

服务以 root 身份写入，只读界面为当前用户运行。目录和快照必须由 root 持有、不允许组或其他用户写入，拒绝额外 ACL；快照为单链接普通文件，权限 0644。通过目录描述符访问，不跟随祖先或最终符号链接。临时文件写入后 fsync，再原子替换。遇到不可信现有文件直接失败，不修正管理员权限设置。

## 界面验证与新鲜度

Swift 读取器固定路径、固定 root 所有者，无 CLI、环境变量或配置路径覆盖。文件读取最多 4096 字节，拒绝 FIFO、额外硬链接、ACL、不安全权限、类型或字段错误。读取前后比对描述符和路径的 inode、大小及修改时间，避免将变化中的内容视为可信快照。此边界防止非特权用户伪造状态；不宣称可防御恶意 root。

界面每 30 秒刷新，并在菜单打开时刷新。快照年龄超过 150 秒或超前超过 30 秒均显示过期；缓存的正常状态也重新计算年龄。失败时不会退回旧绿色状态。七项全真仅表示“最近检查正常”，不是实时在线证明，也不能代替服务端入网、执行阻断和生产验收。

## 验证与未完成事项

Python 测试覆盖白名单、严格布尔/版本/时间、原子替换、失败保留、链接/FIFO/权限/所有者拒绝、非生产模式不发布和线程退出边界。Swift 测试覆盖实际 macOS ACL、符号链接、硬链接、FIFO、权限、大小、格式和过期边界。CI 在两种原生架构将 Python 发布器的合成快照交给 Swift 读取器验证兼容，并构建独立 app 候选。

真实生产目录的持续发布与 UI 联动尚需端到端验证。界面尚未并入 pkg、可信更新和卸载事务；自动启动、受保护手动扫描接口、用户/Agent 通知和纠偏反馈仍待实现。不能将本只读状态增量标为统一客户端交付完成。签名公证和 [R7 完整验收](MACOS-RUNTIME-CONTRACT.md) 继续保持发布门禁。
