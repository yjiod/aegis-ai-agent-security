# 架构与信任边界

## 数据流

1. Intune 以 SYSTEM/root 安装经过 SHA-256 固定的 Agent、策略和编码基线。
2. 周期任务通过文件系统标记发现 AI Coding 工具，不执行被发现的二进制。
3. Agent 自动同步带托管标记的基线，扫描 Skill、MCP、代码和依赖清单。
4. 报告原子写入受限目录；配置上报后，以 Bearer 与 HMAC 发送到 Collector，失败则进入有界离线队列。
5. Collector 严格验证报告契约、签名、时钟窗口和大小，将规范化报告写入 SQLite WAL。
6. Adapter Worker 从 Collector 的已验证报告生成最小厂商事件，以派发账本、稳定幂等键和有界失败队列连接深信服、联软及安全 Webhook；各目标相互隔离。
7. 私有控制台通过同源服务端代理读取 Collector 聚合摘要，浏览器无法取得 Collector 令牌。

## 信任边界

- **终端不可信输入**：项目文件、Skill、MCP 配置、依赖清单和用户规则。解析必须有大小/数量边界，不执行内容，不跟随越界链接。
- **MDM 管理边界**：Intune 负责脚本身份、文件分发和条件访问。哈希固定防止下载源变化；生产仍需脚本签名与分阶段分配。
- **报告边界**：报告只包含脱敏路径和受限证据。Collector 验证发现项与汇总计数一致。
- **厂商边界**：终端永不直连 EDR/桌管管理面。Adapter 只允许精确 HTTPS 主机和待审批动作。
- **控制台边界**：Sites 为私有站点。只读代理限制目标、超时、响应大小、UTF-8 与返回字段；任务下发 API 尚未实现。

## 失败模式

- 策略损坏：Python 保留 last-known-good；Windows 报告高危状态。
- 网络中断：报告与厂商事件进入权限受限、有界、可隔离损坏项的队列。
- Collector 异常：健康检查与 API 返回 503，不伪装为客户端错误。
- 报告或版本漂移：Intune 合规失败，Collector 摘要显示版本姿态。
- 回滚校验失败：周期任务保持停止，Intune 检测进入修复态。

## 客户环境验收项

- 深信服 EDR 与联软具体版本的正式 API 路径、鉴权和字段映射。
- Intune 试点组、条件访问阈值、脚本签名和凭据注入。
- Collector 企业 TLS/mTLS、反向代理、备份与监控。
- 控制台到客户 Collector 的私有网络通道和只读服务账号。
