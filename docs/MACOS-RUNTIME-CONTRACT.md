# Mac 客户端运行时交付契约

本契约落实 [产品硬约束 R7](PRODUCT-REQUIREMENTS.md#r7mac-客户端零外部-python-依赖)。状态：要求已确认，现有实现未验收。此文件不修改受管安全基线。

## 交付边界

用户不需要预装、配置或升级 Python。不得调用 `/usr/bin/python3`、PATH 中的解释器、Homebrew Python、pip，或为运行客户端临时下载 Python。构建和开发测试工具可以使用 Python；自包含程序内封装的运行时必须随正式工件完整分发和维护。

这一约束覆盖服务、界面、安装与入网、基线与治理、策略验证、可信更新、修复、回滚、诊断和卸载。安装正常但卸载需要 Python，也属于发布失败。ARM64 与 x64 必须分别有证据，Rosetta 执行不能冒充 Intel 原生验证。

## 已确认缺口与实施顺序

| 入口 | 当前状态 | 必须完成的工作 |
| --- | --- | --- |
| `scripts/build-macos-pkg.sh` | 缺少冻结二进制时仍能生成 Python 脚本包，安装期选择解释器 | 正式构建要求完整双架构载荷、架构/版本/来源校验，安装入口移除外部解释器回退 |
| `scripts/build-macos-standalone.sh` 及其安装器头部 | 缺少二进制时退回 Python 形态 | 独立包采用相同自包含运行时；不能通过另一下载入口绕过要求 |
| `public/downloads/uninstall-aegis-macos.sh` | 已改为调用客户端内嵌维护模式；缺件或能力自检失败时拒绝，不回退 Python | 结合最终自包含安装包验证完整卸载、保留用户内容、归档和失败恢复 |
| `build-agent-binaries.yml` | 双原生架构冻结，维护模块内嵌；构建工具链版本及 wheel 摘要锁定，源码与冻结维护测试纳入 CI | 冻结测试不等于无 Python 终端全生命周期验证；最终包、可信构建及发布仍须验收 |
| MDM、在线引导、诊断、更新、修复、回滚及 Swift 界面 | 尚未完成全入口依赖审计 | 逐入口跟踪调用链；任何必需能力依赖外部解释器即阻止发布 |

现有脚本候选产物仅可用于开发验证，不能因它能在开发机上运行就认定可交付。以上是实现待办；目前构建脚本尚未强制执行新的发布规则。

优先集成自包含服务与维护能力，再收紧正式构建和所有安装入口，随后完成可信更新/回滚及干净环境测试。保留可重复的开发源码测试，但不能用其替代最终客户端验收。

## 验收证据

每个系统版本与架构记录对应提交、工件摘要、签名/公证状态、环境条件、操作结果和失败路径，不记录真实设备身份、凭据或用户文件内容。

- 无外部 Python、Homebrew、开发工具的环境完成全新安装、入网、服务启动及重启后恢复。
- 使用合成样本验证基线、Skill/MCP 治理及诊断；联网功能分别验证成功与离线待处理状态。
- 完成策略验签、客户端升级、升级失败回滚、修复安装和卸载；卸载失败必须保留可恢复状态。
- 在存在不兼容 Python、恶意同名 PATH 程序和 Python 环境变量的环境中，客户端不使用外部解释器或加载外部 Python 模块。
- 对最终载荷、启动配置和整个执行链检查外部解释器依赖；仅检查 Mach-O 外层动态链接不足以通过验收。
- 签名、公证和受信任升级另有门禁；自包含与可信发布必须同时满足。

开发机测试、模拟架构选择和只修改 PATH 的测试可提供局部证据，但不等于干净终端全生命周期验收。所有适用入口通过前，本条保持未完成。
